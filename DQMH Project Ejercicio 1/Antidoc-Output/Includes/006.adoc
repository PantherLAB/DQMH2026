|#DQMH_HowTo This VI is based on the Simple State Machine project template. It illustrates how to use non-DQMH code to call DQMH modules. In this simple state machine VI (which is the top-level application for the DQMH project template), there are several calls to the Public API VIs of the Singleton and Cloneable DQMH modules that are also part of the DQMH project template. For more illustrations of how to call DQMH modules from non-DQMH applications, browse the DQMH examples located at [LabVIEW 20xx]\examples\DQMH Consortium.
See the following video for a walkthrough of this application functionality: https://bit.ly/DQMHProjectTemplateApplicationWalkthrough
Documentation available via Help > DQMH Consortium > DQMH Help... menu.
